# BeProject | Gestão de Funcionários

Aplicação web para visualização e pesquisa de funcionários, desenvolvida com **React, TypeScript e Vite**, com foco em componentização, organização de código e responsividade.

[**Acessar aplicação online**](https://suelemmacedo.github.io/BeProject/) · [**Ver código-fonte**](https://github.com/suelemmacedo/BeProject)

## Funcionalidades

- Listagem de funcionários com foto, nome, cargo, data de admissão e telefone.
- Pesquisa de funcionários por nome.
- Layout responsivo: tabela no desktop e cartões no celular.
- Formatação de datas e telefones.
- Tratamento de carregamento e erros.
- Consulta a dados fictícios em JSON.

## Executando localmente

**Pré-requisitos:** Node.js, npm e Git.

Clone o repositório:

```bash
git clone https://github.com/suelemmacedo/BeProject.git
cd BeProject
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

Acesse o endereço informado pelo Vite no terminal.

Os dados de demonstração são disponibilizados pelo arquivo `public/db.json`, sem necessidade de iniciar um servidor de API separado.

## Qualidade do código

Para executar as verificações:

```bash
npm run lint
npm run build
```

## Evolução do projeto

O BeProject teve origem em um desafio técnico de frontend e passou por uma refatoração para aprimorar sua estrutura e experiência de uso.

As principais melhorias incluíram separação de componentes, tipagem com TypeScript, organização da camada de serviços, tratamento de estados da aplicação, ajustes visuais e adaptação para dispositivos móveis.

O projeto também utiliza Git e GitHub para versionamento e GitHub Pages para publicação.
